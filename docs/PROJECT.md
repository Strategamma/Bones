Skull is a phone-first canvas web game in vanilla JS/Vite, branded as BONES in the app shell and opening UI. It supports separate server-backed LAN and internet tables only; there is no pass-and-play mode. `server/game.js` owns authoritative 3–6-player rules and private hands; `server/index.js` serves the build and WebSocket rooms. Seat tokens are browser-local; they are not identity. The server pauses on disconnect and connected players vote to continue with deterministic host transfer. LAN rooms default to `data/rooms.json`; Render internet rooms are ephemeral unless `DATA_FILE` points to durable storage. Keep Render to one instance. `network.js` draws multiplayer states in the same canvas, while an accessible DOM form collects names, server URLs and codes. Vite uses `/Bones/` as its base for both GitHub Pages and the Node server. GitHub Pages defaults internet tables to `https://bones-lfxr.onrender.com`; invite or saved server URLs take precedence. LAN phones navigate to the local host through `bones.local`. Saved player names take precedence over editable arcade URL hints. The matte 3D wordmark at `public/assets/bones-platform-logo.png` is shared by the arcade listing, canvas menu/phase headers and table setup; PNG sizes serve the PWA icon. Canvas UI uses original SVG artwork in `public/assets` with fallback drawing and reduced-motion-aware animation. First disc cycle gives each active player one placement, then the next player may place or bid; bid cap is the current stack total and bidding locks placement. Server views include `resultKind` for point/skull reward UI. Canvas animation is state-driven in `src.js` at about 30fps; reduced-motion keeps feedback static. Render Blueprint builds with dev dependencies and runs one Node internet service; a 2-minute client WebSocket heartbeat prevents idle Free spin-down during open tables, but Free room data remains ephemeral. LAN uses the same server locally and can save rooms to disk.
Rooms are separate by six-character code. Native LAN hosting uses the same Node server in LAN mode, with `server/lan-discovery.js` answering `bones.local` over mDNS so the public game's LAN entry can navigate to it without an IP. One host computer is required; advanced manual address fallback remains for networks that block mDNS. The host can transfer control to a connected player at any stage and remove a player in the lobby; the server enforces both. The menu offers a PWA install control, with browser-specific guidance when a prompt is unavailable. Illustrated help is a DOM dialog in `rulebook.js`; `audio.js` synthesizes short Web Audio cues after user input and stores the sound preference. Matte SVG assets and `UIUXVisions.md` define the current theme.
