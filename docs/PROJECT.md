BONES is a phone-first Skull game in vanilla JS/Vite, with separate LAN and internet tables and one private hand per device. No pass-and-play. `server/game.js` owns authoritative rules, private views, scoring and removal; `server/index.js` serves the `/Bones/` build and WebSocket rooms. Start requires 3–6 connected players; elimination can leave fewer. Seat tokens are browser-local reconnect credentials, not identity. Internet defaults to `https://bones-lfxr.onrender.com`; invite/saved addresses take precedence. Render uses one Node 22 instance; Free rooms are ephemeral unless DATA_FILE points to durable storage. A two-minute WebSocket heartbeat keeps open tables active.

LAN requires one computer running the local Node host. `server/lan-discovery.js` answers `bones.local` over mDNS; some phones need the fallback private IP printed by the launcher. Public HTTPS entry navigates to the local HTTP host, with saved connection details behind help. LAN persistence defaults to `data/rooms.json`; restored active rooms are paused. Discovery covers rooms on the connected host, not separate computers across the network.

LAN entry automatically reclaims a saved seat or joins the first connected lobby with space; otherwise it creates a room. LAN-only directory subscriptions publish code, host name, occupied/connected seats, capacity and waiting/playing/paused/finished status without private cards/tokens. Offline-only rooms are hidden. Explicit room switching removes the old seat; empty rooms are deleted. Browsing keeps the current game connected. Disconnections reserve seats and pause play; connected players vote to continue. Auction recovery skips passed players; disconnected eliminated hosts also permit host migration. Hosts can transfer control or remove players. Removing during play cancels the unfinished round, returns remaining cards, preserves points and safely reindexes peers; one survivor wins. Optional names can change in the lobby. Invite links reclaim matching saved seats and update their code after room switching.

`network.js` renders multiplayer canvas states plus DOM setup, room browser and dialogs. `src.js` owns art, input, state-driven motion/rewards, a text-state hook and time stepping. The canvas scales from its rendered rectangle, not window size. First placement is simultaneous; the starter leads clockwise add/bid turns. One-tap bid numbers lock placement. Reveals select an unopened original index directly on colored table cards, highlight then confirm; own stack comes first. Skull owners immediately discard a shuffled hidden card. Two points wins; rematch resets hands and points. Original SVG assets include rectangular faces, six colored backs, arcade navigation and reward scenes; the BONES PNG wordmark is shared with the arcade and PWA icons. Labeled Home/Rooms/Host/help controls stay available; rare address/code inputs are collapsed. Menu teaches the two-point goal, cards say Safe Flower/Skull Trap, and victories show crown, score and match summary. One illustrated felt table replaces separate seat boxes. Played cards use larger responsive DOM targets with keyboard selection/confirmation. Reduced motion keeps feedback static while timed notices still clear. `rulebook.js` provides illustrated help; `audio.js` synthesizes cues with persistent mute. Service-worker upgrades reload public assets. `UIUXVisions.md` records design conventions. Node rule/transport tests and in-app-browser QA verify changes; standalone Chromium launch is blocked by the macOS sandbox. Real-device LAN and installed offline behavior require separate verification.
