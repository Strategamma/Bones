Skull is a phone-first canvas web game in vanilla JS/Vite. It supports pass-and-play plus separate server-backed LAN and internet tables. `server/game.js` owns authoritative 3–6-player rules and private hands; `server/index.js` serves the build and WebSocket rooms. Seat tokens are browser-local; they are not identity. The server pauses on disconnect and connected players vote to continue with deterministic host transfer. LAN rooms default to `data/rooms.json`; Render internet rooms are ephemeral unless `DATA_FILE` points to durable storage. Keep Render to one instance. `network.js` draws multiplayer states in the same canvas, while an accessible DOM form collects names, server URLs and codes. Vite uses `/Bones/` as its base for both GitHub Pages and the Node server. GitHub Pages remains suitable for pass-and-play and connecting to Render; LAN phones should open the local server URL. Arcade URL names are editable display hints only.
