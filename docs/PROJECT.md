Skull is a phone-first canvas web game in vanilla JS/Vite. It supports separate server-backed LAN and internet tables only; there is no pass-and-play mode. `server/game.js` owns authoritative 3–6-player rules and private hands; `server/index.js` serves the build and WebSocket rooms. Seat tokens are browser-local; they are not identity. The server pauses on disconnect and connected players vote to continue with deterministic host transfer. LAN rooms default to `data/rooms.json`; Render internet rooms are ephemeral unless `DATA_FILE` points to durable storage. Keep Render to one instance. `network.js` draws multiplayer states in the same canvas, while an accessible DOM form collects names, server URLs and codes. Vite uses `/Bones/` as its base for both GitHub Pages and the Node server. GitHub Pages can connect to a Render internet server; LAN phones should open the local server URL. Arcade URL names are editable display hints only. Canvas UI uses original SVG artwork in `public/assets` with fallback drawing and reduced-motion-aware animation. First disc cycle gives each active player one placement, then the next player may place or bid; bid cap is the current stack total and bidding locks placement. Server views include `resultKind` for point/skull reward UI. Canvas animation is state-driven in `src.js` at about 30fps; reduced-motion keeps feedback static. Render Blueprint builds with dev dependencies and runs one Node internet service; a 2-minute client WebSocket heartbeat prevents idle Free spin-down during open tables, but Free room data remains ephemeral. LAN uses the same server locally and can save rooms to disk.
