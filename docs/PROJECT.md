Skull is a mobile-first, single-device pass-and-play web game using a canvas UI and vanilla JavaScript. It follows classic 3 flowers + 1 skull rules for 3–6 players. Each private turn uses a handoff screen. The game is an offline-capable PWA; it does not claim network multiplayer. Arcade URL names are editable display-name hints only. Vite builds with `/Bones/` as its base for GitHub Pages. `.github/workflows/pages.yml` builds and uploads `dist`; Pages must use GitHub Actions as its publishing source.
