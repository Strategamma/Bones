BONES is a phone-first Skull game in vanilla JS/Vite. `server/game.js` owns authoritative rules, private hands, scoring and removal; `server/index.js` serves `/Bones/` and WebSocket rooms. Three to six start; elimination can leave fewer. Internet defaults to `https://bones-lfxr.onrender.com`. Render requires one Node instance; persistent recovery needs durable DATA_FILE storage. LAN persistence defaults to `data/rooms.json`; restored active rooms pause.

LAN needs a computer running `npm run lan`. `server/lan-discovery.js` answers bones.local; use the launcher’s private IP when resolution fails. Browsers discover rooms only on their connected host, not nearby computers. Guest isolation/firewalls can block access. Local hosting works without internet; the public online host requires internet. LAN hello advertises the local URL so loopback invitations use the host IP. Internet invitations from a local preview use the public server’s `/Bones/` page.

Entry is one tap after prerequisites: LAN reclaims a saved seat or joins/creates an available room; online offers join/create; invitations join directly. First visit prompts for a locally saved name; home pencil edits it. Standalone PWA hides Install. Menu uses Sound/Rules icons and online-code fallback; Rooms/Arcade buttons are omitted. Active arcade exit confirms and preserves the saved seat; Home strips invite routing so reload does not unexpectedly rejoin. Connections allow 10 seconds locally, 45 online, with busy states, scoped retries and expiry recovery.

Server capabilities hide unsupported controls; legacy placement follows turn cues. Modern guests explicitly ready up; host Start implies consent. Lobby disconnect resets readiness. Bots are ready automatically, use private views, act with paced timers, vote on pauses, persist and never host.

Room browsing preserves connections; switching removes the old seat. Empty rooms disappear. Disconnect reserves seats and pauses active play; connected survivors vote to continue and transfer disconnected hosting. Missing revealers/skull owners may require reconnection/removal. Lobby/win hosting migrates to a connected human. Removal ends an unfinished round, preserves points and reindexes peers. Protocol heartbeat detects silent loss.

Modern first placement is simultaneous; starter leads clockwise add/bid turns. Bidding locks stacks. Server opens the winning bidder’s own stack with paced flips; opponent choices stay manual. Skull loss automatically discards one shuffled card. Gold-filled mats mark points. Two points wins. Session wins persist across rematches/reconnects as lobby flowers; new seats start at zero. Rematch opt-ins count once per human; bots consent automatically. Guests opt in; host selects the lineup and explicitly starts. Host Rematch immediately opens seat management, retaining votes as lobby readiness; bot fill and confirmed kicks precede explicit Start. Return to Lobby keeps identities/displayed scores, clears old cards/bids and resets readiness; Start resets the match.

`network.js` owns UI flows; `src.js` renders original ivory/plum/coral/mint clay art and snapshot-driven rewards. Canvas controls retain focus, scroll focused actions into view, reject drags/repeated activation and respect modal gates. Uniform canvas scaling keeps artwork proportional. Phones use two-column mats; wide screens use three columns and separate hand/action zones. DOM controls share canvas geometry. Short screens scroll. Menu contains secondary tools; Rules, sound, optional haptics and reduced motion persist. Results actions immediately skip brief celebrations. `docs/INTERFACE_COVERAGE.md` records evidence and deployment/device limits; `UIUXVisions.md` holds design conventions.
